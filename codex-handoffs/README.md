# Codex handoffs

Add explicit tasks as `TASK-XXXX-short-title.md` with expected behavior, affected
modules, reproduction steps, previous attempts and acceptance criteria.

Each result must document changes, executed and unexecuted checks, risks and
integration steps under `## CODEX-ERGEBNIS`. Use
`IMPLEMENTED_AWAITING_REVIEW`, `PARTIALLY_IMPLEMENTED`, `BLOCKED` or
`REQUIRES_USER_ACTION`; final project acceptance requires the agreed review gates.
